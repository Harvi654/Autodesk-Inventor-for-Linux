# v0.4.0 - same installation as on Windows, GPU ray tracing in 2027, prefix migrations

<!-- Release notes for the GitHub release of tag v0.4.0 (the maintainer
creates the signed tag and the release; this text is its body, e.g. with
gh release create --notes-file). Earlier releases have their notes only on
GitHub. -->

Inventor 2027 is now installed the way Autodesk's installer does it on
Windows - compared file by file and key by key, base and update - and
existing installations follow new changes by themselves. GPU ray tracing
works in Inventor 2027, 3D PDF and Import CAD work, and Wine is now
[winum](https://github.com/Harvi654/winum).

### Supported releases
- **Inventor 2027: fully supported** - compared with Autodesk's installer
  on Windows, updates tested, new work goes there. Use it for new
  installations.
- **Inventor 2026: maintained** - it keeps working through the shared
  code, but is no longer compared with Windows or tested after each
  change. When 2028 comes out, 2026 drops out. See README "Supported
  releases".

### New since v0.3.1
- **The installer gives the same result as Autodesk's installer on
  Windows**, base and update (the installer completeness review, #14,
  [docs/installer-completeness-review.md](https://github.com/Harvi654/Autodesk-Inventor-for-Linux/blob/v0.4.0/docs/installer-completeness-review.md)):
  every application of the image as ODIS installs it, the image's
  `setup.xml` properties and setup UI settings, `INSTALLDIR` for every MSI
  package, ODIS's standard MSI properties, the packages' path mappings,
  DWG TrueView before Inventor as on Windows. After the fixes no file of
  Inventor and its applications is missing compared with a Windows
  installation of 2027 + 2027.2; what still differs is ODIS's own
  bookkeeping, files Windows writes at run time for the user, and what is
  left out on purpose (below).
- **DWG TrueView and the Electrical Catalog Browser are installed by
  default**, as on Windows (`--no-trueview`, `--no-electrical`, and
  switches in the GUI, leave them out). The Catalog Browser needs
  Microsoft's Access Runtime, as on Windows; tested with Microsoft's Access
  Database Engine 2016 installed by hand (an optional installer step for
  it is planned).
- **Inventor's own registration** runs once after its packages
  (`Inventor.exe /install 0`, without a window): the COM server
  `Inventor.Application` and the document types, as Windows' installation
  registers them.
- **`tar.exe`** in the prefix: libarchive's signed Windows build of bsdtar
  3.5.3, pinned and SHA-256 checked - Windows 10 ships bsdtar as
  `System32\tar.exe`, and the Electrical Catalog Browser's installer
  unpacks with it.
- **Updates remove what they drop:** an ADIX update (e.g. 2027.2) replaces
  its own files and moves the files its new version no longer has into a
  backup in the prefix, as Windows removes them - nothing is deleted.
- **Prefix migrations:** an installed prefix is brought up to date step
  by step, by the launcher at every start (or `scripts/migrate-prefix.sh`).
  Each step saves what it changes first and puts it back if it fails; a
  step that needs a download is put off while offline and never blocks
  Inventor's start. The steps so far:
  - 0001 the earlier prefix setup, 0002 `wineboot -u` for a new Wine,
    0003 the X11 settings for Inventor, 0004 `EnableHydra` (optional);
  - **0005** Inventor's registration;
  - **0006** `tar.exe`;
  - **0007, 0008** `%PUBLIC%` paths written unexpanded into Autodesk's
    registry strings (64- and 32-bit view);
  - **0009** winum's vkd3d-proton;
  - **0010** the default add-ins on;
  - **0011** Wine's menu builder off in the prefix itself (#23).
- **GPU ray tracing in Inventor 2027** (tested on AMD RX 6400 and RX 9060
  XT, NVIDIA RTX 5080): with winum's opengl32 fix and **winum's
  vkd3d-proton** `3.0.1-winum-1` (upstream 3.0.1 plus a ray payload fix in
  dxil-spirv), now installed by the script installer as well as by NixOS
  (#17, #19). Turn it on with **Application Options > Hardware > Graphics
  Driver = DirectX 12**, then tick "Enable Viewport GPU Ray Tracing".
  Needs a card with hardware ray tracing and a Vulkan driver that
  supports it.
- **3D PDF works:** the installer puts Microsoft's .NET Framework 4.0
  (pinned) and the install image's own .NET Framework 4.8 into the prefix
  in place of wine-mono.
- **Import CAD in Inventor 2027** (issue #10, "Property Mapping on
  imported CAD crashes in 2027"): Property Mapping no longer crashes (it
  runs on .NET Framework 4.8 instead of wine-mono), and importing a STEP
  file into an assembly works instead of failing with "Could not import
  object" (four ole32/packager fixes contributed by @krokosik, in
  winum-11.20-2).
- **Add-ins on by default**, as on Windows (#20): Feedback,
  PerfFeedback, Interactive Tutorial, Fusion translator, and Shared Views
  with .NET Framework 4.8. Only the Autodesk Assistant stays off (its
  panel is drawn wrongly under Wine); `bash scripts/addins.sh enable
  assistant` turns it on.
- **Wine: winum** in place of this project's own build: vanilla Wine 11.20
  with 66 documented patches, built in public, every patch with a Wine
  test that passed on Windows 10 or a recorded reason why not. This
  release uses `winum-11.20-2`.
- **Disk and memory checks with measured numbers** (#21): what goes to
  each disk (prefix, unpacked download, Wine) is added up per filesystem
  and compared with its free space; memory below 16 GB gives a warning
  (never a stop). Measured: a full 2027 installation is about 20 GB, the
  unpacked download 11 GB (can be deleted afterwards), Wine 1 GB; plan for
  40 GB. README "Requirements" lists processor, memory, graphics and disk.
- **Fixes from fresh installations** (#22, #23):
  - the .NET Framework 4.0 step of a 2026 installation could hang for
    good: a captured `wine reg query` waited for the prefix's services
    (FlexNet licensing, Edge update), which inherit its output and never
    exit - captured wine calls now return when wine exits;
  - `install.sh --skip-packages` no longer asks for sudo;
  - a plain `wine ...` in a terminal could let Wine's menu builder put 18
    file associations and the sign-in protocol for the prefix into the
    application menu, bypassing the launcher - the menu builder is now off
    in the prefix itself (migration 0011), and those entries are removed.
- **Ubuntu 26.04 and Fedora 44:** clean installations of Inventor 2027 in
  a VM (Ubuntu with 3D PDF and Stress Analysis), Fedora in a first test.
- **NixOS** (@krokosik): DXVK and vkd3d-proton as runtime layers above the
  installation (#17); the installation built on a base without Wine Mono,
  with the .NET 4.8 layer; the complete installer test suite runs in the
  Nix sandbox and in CI (#16); a sign-in dispatcher that routes Autodesk's
  sign-in callback to the running release (#12); winum candidates without
  rebuilding the installation; UI fonts (#9).
- **Setup:** a new icon for "Inventor on Linux - Setup".

### Not installed on purpose
- **ODIS and Autodesk Access:** this project's installer takes ODIS's
  place and keeps its own record of what it installed; updates come from
  Autodesk's update download, run through the same installer. Writing
  ODIS's bookkeeping (UPI2, uninstall entries) would claim an ODIS
  installation that does not exist, and Access or ODIS, if ever started in
  the prefix, would act on packages they did not install.
- **CER (Customer Error Reporting):** Autodesk's crash reporter and its
  service; its uploader is moved aside, so no crash data is sent.
- **Autodesk Genuine Service:** installed by Windows by default (the
  manifest marks it optional). Under Wine its installer fails (its
  `killBeacon` action needs Windows PowerShell, 1603), so it stays off; it
  is Autodesk's check for non-genuine software, not the licensing -
  Inventor licenses without it. `--with ags` tries it.

### Known issues
- **GPU ray tracing in Inventor 2026 is not supported:** 2026 has no
  DirectX 12 graphics driver, and its Direct3D 11 viewport would need
  Direct3D 12 -> 11 shared textures, which DXVK and Wine do not have
  (krokosik's #3 got 2026.4 working with patches this project does not
  carry). Clicking it can hang Inventor 2026; untick it - CPU ray tracing
  works.
- After GPU ray tracing, Restore Down and maximising again can leave the
  window drawn shifted until it is minimised and restored. (The status bar
  text that stayed after ray tracing has a workaround,
  `ClientSideWithRender=N`, set by migration 0003.)
- First start of Inventor 2027: "The following projects could not be
  found on disk ... `TutorialData.ipj`" - the Interactive Tutorial add-in
  points at its project before a tutorial is downloaded; OK dismisses it.
  Not compared with Windows yet, likely the same there.
- The Interactive Tutorial's window opens at the far right and has to be
  moved by hand.
- A small "Default" window at the top left of Inventor 2027 (cosmetic).
- The Autodesk Assistant's panel is drawn wrongly (off by default).
- The home page can show an old picture after Application Options until
  it is clicked.
- Inventor 2027's Open dialog: no previews, folder names missing in its
  path bar.
- Native Wayland does not work yet; Inventor runs through XWayland.

### Upgrading
```bash
cd ~/inventor-on-linux && git pull && bash scripts/get-wine.sh
```
Or **Inventor on Linux - Setup** -> *Update project and Wine*. Then start
Inventor as usual: the launcher runs the prefix migrations once (Inventor
closed; each step is saved first and put back if it fails).
`bash scripts/migrate-prefix.sh --status` shows what was applied.

- **Coming from v0.3.x** (this project's own Wine `wine-inventor-11.20-6`):
  `get-wine.sh` installs winum, and migration 0002 updates the prefix for
  it at the next start. The old Wine build can be removed afterwards
  (`get-wine.sh` prints its folder).
- **3D PDF and Property Mapping** need .NET Framework 4.8 in the prefix,
  which only a new installation adds - every installation made before
  2026-11-11, so every v0.3.x installation. README "3D PDF and Property
  Mapping in an older installation" has the steps; your files in
  `~/Inventor` stay.
- **DWG TrueView and the Electrical Catalog Browser** come with a new
  installation; in an existing one, running `install.sh` again with the
  same download should add them (finished packages are skipped; not
  tested on an old prefix).
- **NixOS:** pin `github:Harvi654/Autodesk-Inventor-for-Linux/v0.4.0`.
  `programs.autodesk-inventor.versions` no longer defaults to
  `[ "2026" ]`: list the releases you want, e.g.
  `[ "2027" ]` or `[ "2026" "2027" ]` (an empty list gives a warning and
  installs nothing). See [docs/nixos.md](https://github.com/Harvi654/Autodesk-Inventor-for-Linux/blob/v0.4.0/docs/nixos.md).
- Wine 11.22 (`winum-11.22-1`) is released in winum; this project moves to
  it after v0.4.0.
