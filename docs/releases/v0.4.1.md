A fix release for v0.4.0. Wine stays winum-11.20-2; nothing else in the
installation changes.

### Fixed
- **Inventor crashed right after the splash at every start** in an
  installation upgraded from v0.3.x (found by @Lukas10999, thank you).
  Installations from before 2026-11-11 have no .NET Framework 4.8;
  v0.4.0's migration 0010 turned the Interactive Tutorial add-in on, and
  on Wine Mono it crashes Inventor. The new migration **0012** turns it
  off again in a prefix without .NET Framework 4.8. With .NET 4.8 - every
  installation made with v0.4.0 - nothing changes and the tutorial stays
  on. If you used the workaround
  (`bash scripts/addins.sh disable InteractiveTutorial`), nothing more is
  needed.
- **Commands to copy** in the README and in the installer's closing
  messages now put variables on their own `export` line instead of
  `VAR=value bash ...`, which lost the variable when a pasted line wrapped
  and then ran against the default prefix.

### Checked
- Tests: 239 OK, among them 0012 with and without .NET Framework 4.8.
- An older installation upgraded through migrations 0006-0012 in one go
  (Ubuntu, with .NET 4.8): 0012 "already so", Inventor starts, the
  tutorial opens.

### Upgrading
In the Setup app: **Update project and Wine**. Or in a terminal:
```bash
cd ~/inventor-on-linux && git pull
```
Then start Inventor as usual: the launcher runs migration 0012 once. For
3D PDF, Property Mapping, Shared Views and the tutorial, an installation
from before 2026-11-11 needs .NET Framework 4.8 - README "3D PDF and
Property Mapping in an older installation".
