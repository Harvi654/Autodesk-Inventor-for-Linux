A fix release for v0.4.0. Nothing else changes.

### Fixed
- **Inventor crashed right after the splash at every start** in an
  installation upgraded from v0.3.x (found by @Lukas10999). Installations
  from before 2026-11-11 have no .NET Framework 4.8; v0.4.0's migration
  0010 turned the Interactive Tutorial add-in on, and on Wine Mono it
  crashes Inventor. The new migration **0012** turns it off again in a
  prefix without .NET Framework 4.8; with .NET 4.8 (every installation made
  with v0.4.0) nothing changes. If you used the workaround
  (`bash scripts/addins.sh disable InteractiveTutorial`), nothing more is
  needed.

### Upgrading
```bash
cd ~/inventor-on-linux && git pull
```
Then start Inventor as usual: the launcher runs migration 0012 once. For
3D PDF, Property Mapping and the tutorial, an installation from before
2026-11-11 needs .NET Framework 4.8 - README "3D PDF and Property Mapping
in an older installation".
